# Rights and takedowns

## Behavior

Every public media object requires one rights record with source identity,
creator where known, attribution, license or permission basis, review evidence,
obligations, and takedown state.

## Configuration

The approved migration assumes the project owner controls redistribution rights
for current media. That assumption does not replace per-object records.

## Failure modes

Missing rights records, unresolved permission bases, active takedowns, or
incompatible obligations keep an object unpublished and render the local
placeholder instead.

## Security and privacy

Rights evidence must not expose private credentials or unrelated personal data.

## Verification

The release check proves a one-to-one relationship between media and rights
records. No rights catalog has been populated yet.
