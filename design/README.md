# Nazca Railway design references

This folder is the source of truth for deterministic transit-atlas design references. Material Designer was unavailable when the project began, so the project uses the sanctioned framework-native reference route and records the capability limitation here.

The production site remains authoritative. Every reference state is paired with an exact production route, viewport, theme, language, scale, raw capture, side-by-side comparison, visual diff, and documented intentional deviation.
